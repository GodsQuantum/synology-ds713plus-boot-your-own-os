# Security policy

Firmware flashing is safety-critical. Please **do not publish proprietary BIOS dumps, credentials, private IP inventories, or SSH keys** in issues.

For a vulnerability that could cause unintended SPI writes, bypass safety gates, expose secrets, or brick hardware, use GitHub **Private vulnerability reporting**. For non-security hardware compatibility findings, use the hardware report issue form.

Supported security fixes target the latest release and `main`.
